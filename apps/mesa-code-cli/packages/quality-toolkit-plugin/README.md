# Mesa Code quality toolkit

Instruction-only skills: `regression-tests` adds focused coverage; `code-review` checks evidence-backed defects; `security-review` reviews authorized targets defensively without mass-target or destructive testing; `performance-profile` measures bottlenecks before optimization.

Uses tools already available to the Agent and the target project's current scripts and dependencies. Adds no runtime, scanners, benchmark service, or dependency installation. Missing tools and unrun checks must be reported. Changes require specification alignment and preservation of unrelated edits; irreversible actions and external data writes require permission.

This directory provides skill assets only. Catalog registration, bundling, installer delivery, and runtime discovery are separate work and are not established by these files. Version 1.0.0; author Mesa Code; license MIT.
