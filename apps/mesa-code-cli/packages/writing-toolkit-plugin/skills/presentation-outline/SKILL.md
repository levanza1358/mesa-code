# Presentation outline

## Frame the presentation
- Confirm audience, decision, duration, delivery setting, and requested format.
- Gather approved source material and identify facts requiring verification.
- Reject secrets and avoid exposing private material in slide examples or external services.
- Use existing tools, native features, and installed dependencies only.
- Do not assume a slide library, Office application, or rendering service exists.
- Default to an outline unless a slide artifact is requested and supported.

## Build the narrative
- Define one takeaway and a specific audience action.
- Order context, problem, evidence, options, recommendation, and next steps as appropriate.
- Budget slides and speaking time to match the session rather than a fixed template.
- Give each slide a message title, purpose, content bullets, and suggested visual.
- Include speaker notes for assumptions, transitions, and likely questions.
- Identify source references for figures, quotations, and factual claims.
- Label estimates, illustrative data, uncertainties, and missing evidence clearly.
- Never invent statistics, customer endorsements, approvals, or citations.
- Prefer readable charts; include units, time ranges, and non-color status cues.
- Preserve source documents, encoding, formulas, and user-edited content.
- Keep sensitive details out of public-facing versions until approved.

## Review and deliver
- Check narrative continuity, timing, arithmetic, and source-to-slide traceability.
- Distinguish proposed visuals from visuals actually generated or rendered.
- If binary slides are unsupported, provide a useful text outline and disclose the limit.
- Avoid converting an existing deck if unsupported features would be lost.
- Obtain permission before overwriting an existing outline or deck.
- Ask permission before publishing, deleting, deploying, or committing materials.
- Return slide-by-slide outline, source list, open questions, and artifact path if created.
- Do not describe outline completion as a rehearsed or rendered presentation.
