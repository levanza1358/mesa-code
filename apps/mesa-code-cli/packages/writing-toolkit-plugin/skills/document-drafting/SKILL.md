# Document drafting

## Confirm the brief
- Establish audience, purpose, tone, length, source material, and output format.
- Identify required sections, approval owner, and any legal or organizational constraints.
- Reject secrets; request sanitized material and avoid sharing confidential drafts externally.
- Inspect available tools and installed dependencies before promising binary Office output.
- Prefer plain text, Markdown, or native platform capabilities when they meet the request.
- Do not invent converters, install libraries, or guarantee Office tooling is present.

## Draft deliberately
- Build a short outline around the reader's decision or action.
- Use supplied facts and verified references; label unsupported assertions for review.
- Distinguish evidence, interpretation, recommendation, and placeholders.
- Keep names, dates, amounts, units, and quoted text faithful to source material.
- Preserve original files, encoding, user edits, and unrelated sections.
- Preserve tables and formulas when editing spreadsheet-derived material.
- Avoid lossy format conversion; disclose unsupported layout or document features.
- Do not manufacture citations, signatures, approvals, or professional certification.
- Use headings, concise paragraphs, and descriptive link text for readability.
- Ask only blocking questions; leave explicit placeholders for missing noncritical details.

## Review and deliver
- Check internal consistency, calculations, references, and requested length.
- Separate substantive revisions from copy edits when approval matters.
- Show a bounded diff or revision summary rather than silently replacing user work.
- Reopen generated artifacts using available readers; do not claim rendering not observed.
- Report unresolved facts, format limits, and checks not performed.
- Obtain permission before overwriting an existing document.
- Ask permission before publishing, deleting, deploying, or committing deliverables.
- Return the draft or artifact path and concise review notes.
- Keep approval and external distribution separate from drafting completion.
