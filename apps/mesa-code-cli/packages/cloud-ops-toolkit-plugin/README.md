# Cloud ops toolkit

Instruction-only Mesa Code skills: `deployment-plan` plans authorized, reversible releases; `container-image-review` audits Dockerfiles and images; `observability-setup` designs metrics, logs, and alerts; `cost-review` finds evidence-backed cost reductions.

Uses tools, native features, and dependencies already declared in the active project. No MCP service, runtime, cloud SDK, account, or cluster access is bundled or guaranteed. Never log credentials or secrets, never run destructive deploy or delete steps without authorization, and report unverified limits honestly instead of claiming cloud behavior that was not observed.
