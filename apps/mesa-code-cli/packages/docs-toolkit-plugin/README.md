# Mesa Code docs toolkit

Instruction-only skills: `readme-authoring` writes a project README from real capabilities; `api-reference-docs` documents exported interfaces; `changelog-release-notes` summarizes verified changes; `docs-site-structure` organizes a documentation site with existing tooling.

Uses the target project's current scripts, generators, and dependencies. Adds no runtime, static-site engine, documentation framework, or dependency installation. Missing tools and unrun checks must be reported. Changes require specification alignment and preservation of unrelated edits; publishing and external writes require permission.

This directory provides skill assets only. Catalog registration, bundling, installer delivery, and runtime discovery are separate work and are not established by these files. Version 1.0.0; author Mesa Code; license MIT.
