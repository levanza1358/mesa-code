# Mesa Code testing toolkit

Instruction-only skills: `test-plan` maps risks to checks; `e2e-scenario` designs end-to-end user journeys; `flaky-test-triage` isolates intermittent failures; `test-data-fixtures` builds deterministic, synthetic fixtures.

Uses test entry points, scripts, and dependencies already present in the target project. Adds no runtime, runner, browser engine, or dependency installation. Missing tools and unrun checks must be reported. Changes require specification alignment and preservation of unrelated edits; destructive actions and external writes require permission.

This directory provides skill assets only. Catalog registration, bundling, installer delivery, and runtime discovery are separate work and are not established by these files. Version 1.0.0; author Mesa Code; license MIT.
