# Mesa Code frontend toolkit

Instruction-only skills: `accessible-ui` checks semantics and keyboard access; `responsive-layout` adapts layouts with native CSS; `theme-audit` checks tokens and preference ownership; `ui-interaction-tests` exercises user journeys with available browser tooling.

Uses tools already available to the Agent and the target project's current scripts and dependencies. Adds no runtime, browser automation engine, UI library, or dependency installation. Missing tools and unrun checks must be reported. Changes require specification alignment and preservation of unrelated edits; irreversible actions and external data writes require permission.

This directory provides skill assets only. Catalog registration, bundling, installer delivery, and runtime discovery are separate work and are not established by these files. Version 1.0.0; author Mesa Code; license MIT.
