# Mobile toolkit

Instruction-only Mesa Code skills: `mobile-layout` adapts layouts to safe areas, touch, and orientation; `native-permissions` reviews mobile permission usage and disclosure; `mobile-offline-sync` designs offline storage and conflict-safe sync; `mobile-release-checklist` prepares store-submission readiness evidence.

Uses tools, native platform features, and dependencies already available in the active environment. No MCP service, runtime, emulator, build toolchain, or store API is bundled or guaranteed. Preserve user work and source data, reject secrets, report unverified limits honestly, and obtain authorization before destructive or externally visible actions such as store uploads.
