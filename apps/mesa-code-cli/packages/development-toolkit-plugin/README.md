# Mesa Code development toolkit

Instruction-only skills: `codebase-map` maps source and owners; `debug-root-cause` diagnoses failures; `safe-refactor` preserves contracts during refactoring; `api-design` specifies validated, compatible API boundaries.

Uses tools already available to the Agent and the target project's current scripts and dependencies. Adds no runtime, executable tools, services, or dependency installation. Missing tools and unrun checks must be reported. Changes require specification alignment and preservation of unrelated edits; irreversible actions and external data writes require permission.

This directory provides skill assets only. Catalog registration, bundling, installer delivery, and runtime discovery are separate work and are not established by these files. Version 1.0.0; author Mesa Code; license MIT.
